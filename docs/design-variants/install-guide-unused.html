Install guide

Every screen, in order

Installing takes about a minute. This page is the long version: what to type, what you should see after each step, and what to do when something doesn't appear. If you'd rather just have the two commands, they're on the front page.

Before you start

  1. 1Claude Code, in a terminal, the desktop app or your editor.
  2. 2Node 20 or newer. Check with node --version.

Nothing else. No account, no API key, no database.

1 min
What you're installing.A plugin: one skill, three hooks, five slash commands and a small CLI called board. It's all in the repo if you'd rather read it first.

Option one

Ask Claude to install it

The one to pick if you're in the desktop app, or if you'd rather not think about marketplaces.

  1. 1Install the Clipped plugin from github.com/avivalushai/clipped
  2. 2Claude asks to run two commands. Approve them. They add the marketplace, then install from it.
  3. 3You should see Successfully installed plugin: clipped@clipped.
  4. 4Start a new session. The commands only load when a session starts.

Works the same in the desktop app, a terminal and the editor extensions — it's the same two commands underneath, which is why asking in words is the most portable way to do it.

Option two

Type it yourself

Two lines, because a marketplace and a plugin are different things: the first says where to look, the second installs from what it found.

Inside Claude Code

  1. 1/plugin marketplace add avivalushai/clipped
  2. 2/plugin install clipped@clipped
  3. 3Start a new session.

Typing /plugin on its own opens a browser you can install from instead, no ids to remember.

From a shell

  1. 1claude plugin marketplace add avivalushai/clipped
  2. 2claude plugin install clipped@clipped

Same thing, outside a session. Installed once, it's there for the terminal, the desktop app and your editor — they all read the same ~/.claude.

Did it work?

Three things to look at

CheckWhat you should see
claude plugin list clipped@clipped, version 0.3.0, status enabled.
Type / in a new session /clipped:board, /clipped:park, /clipped:done, /clipped:ask, /clipped:plan.
Open any project A session in a project with no board yet says so once, and offers to make one. That line is the SessionStart hook working.

First board

Start from work you've already done

Optional. Skip it and the board fills as you work from here. Say this and it starts from what's already in the repo.

  1. 1Set up a board for this project from my recent commits and open branches
  2. 2Claude reads the history, proposes cards, and asks before writing any of them.
  3. 3board ui
  4. 4Opens localhost:4747 with every project that has a board. It updates live while Claude works.

Have a spec or a plan document? /clipped:plan docs/plan.md reads it, shows you what it found, and adds only what you agree to.

When it doesn't show up

The five things that actually go wrong

The /clipped: commands aren't in the list

A session loads its plugins when it starts, so the session you installed from won't have them. Start a new one. If they're still missing, run claude plugin list — if clipped@clipped isn't there, the install didn't finish and you can run it again.

board: command not found

Claude Code puts the plugin's bin on the PATH of sessions it starts, so board works inside a session but not necessarily in a shell you opened earlier. Open a new terminal, or let Claude run it for you — you never have to type board yourself.

Nothing lands on the board while I work

The project needs a board first: say yes when Claude offers, or run board init. After that, cards appear for work that takes more than one reply — a one-line fix is deliberately not a card.

/plugin install can't find it

The marketplace has to be added first — that's what the first command does. Run claude plugin marketplace list: you should see clipped pointing at avivalushai/clipped.

I installed it weeks ago and I'm missing something new

Claude Code caches a plugin under its version number, so a new version has to be fetched: claude plugin marketplace update clipped, then install it again. Your boards aren't touched — they live in your repos, not in the plugin.

Still stuck, or something here was wrong? Tell me — that's what the issues are for.

Leaving

Update or uninstall

Update

  1. 1claude plugin marketplace update clipped
  2. 2claude plugin install clipped@clipped

Boards survive updates. The file format carries a version and migrates itself.

Uninstall

  1. 1/plugin uninstall clipped@clipped
  2. 2Optional: delete .board/ in your projects and ~/.clipped/.

Nothing else is left behind. Your boards are plain JSON you can keep, read or throw away.

Then what?

Nothing. Work the way you already work — the board is written while you do. If you want to see what it's for before you start, the board page shows what it looks like after a few weeks, and what it does and doesn't do is worth two minutes before you trust it with anything.
