What you need

Claude Code, not the Claude chat

Clipped is a Claude Code plugin. It works in the Code tab of the Claude desktop app, in the claude command in a terminal, and in the VS Code and JetBrains extensions.

It does not work in the regular Claude chat (the Chat tab, or claude.ai in a browser). The board is a file inside your project folder, and Claude updates it by running a small command on your computer. Chat can't reach either.

Node 20 or newer

The board command and the three hooks are small Node scripts. To check, open a terminal and run:

$node -v

If it prints v20 or higher, you're set. If it says command not found or an older version, install the LTS version from nodejs.org, then close and reopen Claude.

Without Node the plugin still installs, but the board never updates, and nothing tells you why.

Install the plugin

Pick whichever is easiest. All three end in the same place.

In the Claude desktop app

Slash commands like /plugin don't work in the desktop app, so this takes two parts. First, tell the app where Clipped lives. Open the Code tab, start a session in any folder, and send:

1Run: claude plugin marketplace add avivalushai/clipped

Approve the command when Claude asks. Then install it from the app's plugin menu:

2Click + next to the message box → Plugins → Add plugin, and open Clipped.
3Click the arrow next to Install and choose where it goes:
Install for meEvery project on this computer. Each one still gets its own board.pick this
Install for project (shared)Only this project, written to its .claude/ folder, so anyone who clones the repo gets it too.teams
Install for project (personal)Only this project, only you, kept out of git.trying it out

In a terminal or your editor

Inside claude, one at a time:

1/plugin marketplace add avivalushai/clipped
2/plugin install clipped@clipped

Or from your shell, one line does both, for you, in every project:

$claude plugin marketplace add avivalushai/clipped && claude plugin install clipped@clipped

Or just ask Claude

Paste this into any Claude Code session, desktop app included, and approve the two commands it runs:

›Install the Clipped plugin from github.com/avivalushai/clipped

Restart

Plugins load when Claude starts, so a session that was already open doesn't have it yet.

  • Desktop app: quit it fully (⌘Q on a Mac, not just closing the window) and open it again. Starting a new session alone can leave the slash-command list out of date.
  • Terminal or editor: exit claude and run it again, or type /reload-plugins.

To check it loaded, start a session and type / in the message box. You should see clipped:board, clipped:park, clipped:done, clipped:question and clipped:plan.

Work as usual

Open a session in your project folder and talk to Claude the way you already do. There's no setup command.

The first time something is worth keeping — a feature you start building, a question answered with a comparison or a table, a "let's do that later" — Claude records it, and the project's board appears in a .board/ folder at the top of the project. Short questions and one-line answers stay off the board on purpose.

Want the board to start from what you've already done? Say:

›Set up a board for this project from my recent commits and open branches

Your home folder and hidden folders never get a board. If you work from one of those, open the project folder instead.

Open the board

›/clipped:board

The board opens in your browser at clipped.localhost:4747 (localhost:4747 works too). The sidebar lists every project on this computer that has a board. Keep the tab open: it updates live while Claude works, and new projects appear on their own.

/clipped:board status prints the same summary in the chat instead.

Check it works

In a new session in your project, with the board open next to it, send these one at a time:

You sendThe board should show
Build me a simple web page listing 10 popular mobile games, with a filter by genre.A card under Work, In progress, with the page's file attached
Later we should add a screenshot for each game.A second card, title only, under Idea
What are the top 3 mobile games in each genre?A card under Questions → Answered, holding the picks
Elaborate on that.The same question card, with the fuller answer — no second card
/clipped:parkThe first card moves to Parked, with a note on where you stopped

All five showed up? It works. From here on, just work — you never have to run these commands.

Stop the permission prompts

Claude Code asks before running a command, and Clipped's is called board. You may see Allow Claude to run board …? a few times. It's safe to allow: board only reads and writes .board/board.json in your project and ~/.clipped/.

To stop being asked in every project, add this to ~/.claude/settings.json (create the file if it isn't there):

{
  "permissions": {
    "allow": ["Bash(board *)"]
  }
}

If the file already has a permissions.allow list, add "Bash(board *)" to it instead of pasting a second one.

If something's off

It says /clipped:board isn't a command here

The app's command list wasn't refreshed after the install. Quit the app fully and reopen it, then type / and look for clipped:. If the command runs anyway (you see "Open the Clipped board…" and Claude working), ignore the message.

I worked a whole session and the board is empty
  1. Was it the Code tab, in a project folder? The Chat tab can't use plugins.
  2. Was the session started after installing? Start a new one.
  3. Does node -v print v20 or higher? Without Node nothing gets written.
  4. Was there anything to keep? Quick questions and one-line answers stay off the board on purpose. Try the check above.
Does it work in the Claude chat or on claude.ai?

No. Chat can't read files on your computer or run commands there, and the board is both. Use the Code tab in the desktop app, the terminal, or your editor.

board: command not found in my own terminal

The board command is on Claude's path, not your shell's. Use /clipped:board inside Claude, or ask Claude to run whatever you wanted.

The board landed in the wrong folder

A board goes at the top of the git repo you're in, or in the folder the session was opened in if there's no repo. Delete that .board/ folder and open the session from your project folder instead.

Claude put something on the wrong card

Tell it, or fix it in the board page: open the card and edit it. Files can be detached with board update --unfile.

I'm on Windows

It's untested there. It should work where Node and Claude Code work. If it doesn't, tell me what you see.

Update or remove

Update

Clipped doesn't update itself. When there's a new version:

  • Desktop app: + → Plugins → Manage plugins → Clipped → update, then start a new session.
  • Terminal or editor: /plugin → Installed → Clipped → Update now, then /reload-plugins.
$claude plugin update clipped@clipped

The shell version of the same thing.

Remove

  • Desktop app: + → Plugins → Manage plugins → Clipped → uninstall.
  • Anywhere else:
$claude plugin uninstall clipped@clipped

Your boards stay behind. To remove them too, delete .board/ in your projects and ~/.clipped/. Nothing else is left.
